# 安装诊断报告

安装队列全部结束后，如果存在失败、被阻止、待核验、目录不符或已知清理警告，会显示诊断报告弹窗。正常安装、已安装跳过及仅取消未执行的队列不弹出。报告在用户点击“上传日志”前不会发送。

弹窗提供报告预览、保存报告、暂不上传和上传操作。报告只包括本轮应用结果、安装目录、错误和本轮日志；隐藏用户目录、完整下载地址及常见凭证。不采集电脑名、登录名、IP 或业务软件文件。原始日志仍留在当前电脑；脱敏报告另存于 `%LocalAppData%\HM AppKit\Reports`。

## 固定接收群与构建

正式版的接收群由维护者在构建时固定。程序不读取外置接收配置，不提供地址编辑入口，界面和日志不显示 Webhook 与签名密钥。构建输入只从本机私有文件或 GitHub Actions Secret `HM_APPKIT_SUPPORT_CONFIG` 取得，以下是字段示例，不能填入公开源码：

```json
{
  "Mode": "FeishuWebhook",
  "DisplayName": "公司 IT 反馈群",
  "Endpoint": "https://open.feishu.cn/open-apis/bot/v2/hook/00000000-0000-0000-0000-000000000000",
  "SigningSecret": "由维护者填写签名密钥"
}
```

飞书模式依据[官方自定义机器人说明](https://open.feishu.cn/document/client-docs/bot-v3/add-custom-bot)进行 HMAC-SHA256 签名，脱敏报告分段发送为群消息，每段标记报告编号及序号并限制在 20 KB 请求大小以内。弹窗显示实际发送内容与消息数量，不显示 Webhook 地址和密钥。飞书返回 HTTP 成功且业务码为零才确认发送成功；部分消息失败会显示已确认段数，并停止后续消息，不自动重发。

本地维护构建命令：

```powershell
.\scripts\Build.ps1 -SupportConfigPath '本机私有配置文件的完整路径'
```

脚本为每次构建生成随机 AES-256-GCM 密钥与随机 nonce，将接收配置加密成资源嵌入 EXE；源码和压缩包均不包含明文配置。没有私有输入的本地开发构建仍可保存报告，不能上传；正式 CI 发布缺少该 Secret 时会停止。

**加密只隐藏静态明文，不能防止逆向。** 解密材料随公开客户端分发，能够分析程序的人仍可能提取凭据。需要真正保密时，应将机器人凭据移至公司服务器，由服务器中转。

## 接收接口协议

飞书消息包含报告编号、各应用的结果和本轮脱敏日志。日志最多保留本轮尾部 512 KiB，整个本地报告不超过 768 KiB，截断会明确标记。每条消息标记 `序号/总数`，分段之间节流；飞书对每条均返回业务成功码才显示整份报告发送成功。

客户端只连接飞书官方机器人 HTTPS 地址，不跟随重定向，不读取浏览器 Cookie，不附带 GitHub/Gitee 令牌。分段发送的整轮最长等待 120 秒；取消、业务失败或无法确认时停止后续消息，显示已确认的段数，不自动重发。完整脱敏副本及报告编号保留在本机，便于核对。
