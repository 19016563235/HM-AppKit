# HM AppKit v0.12 一键安装与总体进度

移除“安装预览”按钮及对应事件入口，点击“一键安装”即可执行原有安装队列。队列逐项核验应用配置、已安装状态、目标路径和安装方式，随后检查官方来源、缓存哈希与签名，再执行安装和安装后位置核对。无需先单独生成计划。

底部改为 8px 圆角进度条，显示总体百分比及已有最终结果的应用数量。成功、原已安装、失败、阻止、取消和待核验均属于最终结果；100% 表示本次队列已处理结束，具体成功和异常数量由结果摘要及卡片状态分别说明。检查、下载和当前应用安装期间继续显示当前操作文案，未虚构单个安装包的内部百分比。

既有安装引擎、自身更新、配置与 `Local Installer` 缓存策略继续沿用，柔光多选、低饱和配色与固定计数区域保留。界面验证在隔离进程内注入进度，不执行真实业务软件安装；结果见 [公开验证摘要](../evidence/v0.12-ui/verification.json)。

验证结果：14 项界面检查和 252 项安装、缓存及自身更新回归全部通过。0%、50%、100% 的填充与文字均已检查；高 DPI 的布局舍入按一个物理像素容差核验。当前及历史配置文件哈希未变。
