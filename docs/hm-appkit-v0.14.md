# HM AppKit v0.14

安装队列根据本次实际静默能力稳定排序，支持静默的先执行，京麦等常规向导随后执行。关闭静默时所有应用保持原顺序，取消和超时仍停止后续应用，不会重新运行已有软件。

跳过已安装应用之前核对本次目标目录。目录不符显示“目录不符”，没有足够的位置证据或目录不存在显示“位置待核验”；两者都保留现有安装并计入需关注。普通“已安装跳过”仅表示本次可以核验的位置匹配，结束汇总与本轮新安装分开显示。

微信修复使用厂商插件能够读取的目录参数，见 [微信目录参数说明](weixin-directory-2026-10-16.md)。目录参数的静态分析和构造测试不等同于新机器实际安装复测；本机已有微信没有被重装。京麦目录预填方式已经由用户确认，保持原样，仍核验最终安装位置。

千牛厂商进程的标准输出/错误输出使用 GBK 解码，WinGet、7-Zip 和其他进程保持原来的 UTF-8。京麦释放准备目录时对短暂占用最多清理三次；持续占用或权限不足会保留剩余文件并写一条提示，不强制终止程序。

界面删除页首宣传语和重复的检查更新说明，盘符与根目录集中到同一行，空闲状态简化为“就绪”。保留三列卡片、柔光圆点、固定选择数位置、编辑图标、iOS 开关、日志入口及队列进度。

助手自身更新增加与业务下载同样的有限重试，版本查询和包体读取错误均保留阶段和域名。每次下载尝试使用独占暂存目录，半包不复用，完整校验后才可进入原来的更新替换流程。校验失败、磁盘错误不重试，原配置与安装包缓存不参与暂存清理。GitHub 下载速度取决于网络；Gitee 后续迁移方案见 [说明](gitee-migration.md)，本版不虚构未配置的 Gitee 地址。

公开验证摘要见 [verification.json](../evidence/v0.14-installation/verification.json)。
