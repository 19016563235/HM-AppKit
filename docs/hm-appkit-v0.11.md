# HM AppKit v0.11 柔光圆点

应用多选采用原样式预览中的“柔光圆点”。选中时显示浅蓝色实芯及外围淡色光晕，取消选择时恢复灰色空环。预览中 18px 圆点缩放至 0.62，转换为 11.16px 实芯与 17.36px 光晕外径；光晕为均匀浅色，选中时隐藏原描边。

控件保留原点击区域与 CheckBox 多选绑定。鼠标选中不会额外绘制焦点圈，使用键盘导航仍有独立焦点提示。既有低饱和主界面、固定计数宽度、状态点、安装路径、缓存和自身更新逻辑继续沿用。

验证采用隔离的进程内 WPF 控件，核对选中及取消视觉、多选绑定、计数按钮位置和用户配置哈希，生成主界面及控件预览。未执行业务软件安装，也未向用户桌面注入输入。结果见 [公开验证摘要](../evidence/v0.11-ui/verification.json)。

验证结果：柔光及相关界面检查 8 项通过，五套安装、缓存及自身更新回归 252 项通过，均无失败。用户当前及历史配置哈希保持不变。
