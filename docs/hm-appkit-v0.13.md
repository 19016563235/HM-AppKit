# HM AppKit v0.13 网络恢复与诊断

此前另一台电脑的记录显示：飞书在线下载并静默安装成功；微信在准备安装包阶段请求失败，ToDesk 在包体传输中连接被重置。旧版没有应用层重试，同一异常又经引擎日志与界面状态各记录一次，因此两条相同报错并不代表已经重试。

本版将版本解析和完整安装包传输分别作为网络重试单元。每个单元最多尝试三次，间隔一秒、两秒，已有版本查询及安装包准备时间预算继续生效。重试包含响应体读取，下载中断后从零开始，使用新的独占暂存文件夹，半包不能成为正式安装包。网络连续失败时，只有重新核验通过的旧缓存才允许回退使用。

哈希、数字签名、来源域名、元数据格式、本地磁盘写入和安装程序执行不属于重试范围。用户取消立即停止，不会因重试再次启动安装器，也不会取消已有安装器的保护逻辑。

网络诊断记录实际请求阶段、域名、尝试次数及异常链中的 HTTP、HResult、Socket 错误码。完整签名下载地址、查询参数及认证信息不会写入错误摘要；本地目录与配置错误保留可读原因。同一失败只写入一份详细日志，卡片依旧显示简短失败信息。启动记录包含应用版本，便于对照不同电脑上的结果。

新增网络回归使用小体积假 HTTP 响应和假安装依赖，覆盖断流、提前 EOF、服务暂不可用、取消、缓存保留及不应重试的错误，不执行业务软件安装。另通过生产下载与缓存代码实际下载微信 4.1.15.53、ToDesk 5.2.1.0，核验签名和哈希，再次检查后复用同一缓存文件。测试未运行这两个安装器，也不等同于已在另一台电脑完成安装复测。结果见 [公开验证摘要](../evidence/v0.13-network/verification.json)。
