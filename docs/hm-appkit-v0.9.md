# HM AppKit v0.9 界面调整

已选数量使用与实际计数相同字体、字号和字重的“已选择 9999 个应用”预留空间，数字采用等宽排列。计数从 0 到四位数变化时，全选和清空按钮保持原位。

应用卡片使用选定的“细环实芯”：18px 白底细圆环，选中时显示 8px 蓝色实芯圆心。沿用 CheckBox 独立多选及键盘操作，点击某一应用不会取消其他应用。

状态文字前增加 5px 圆点，正常状态为灰色“待安装”、黄色“安装中”、绿色“已安装”。检查和准备阶段也显示“安装中”，安装成功或安装队列确认原已安装才显示绿色。失败显示红点“失败”，被阻止及待核验显示琥珀色，取消显示灰点“未执行”；详细原因保留在悬浮提示和日志中。

本版调整展示，沿用既有安装队列与状态来源。配置、指定安装目录、默认跳过已安装、程序旁 `Local Installer` 缓存、自身更新和便携运行行为保持一致。

验证方式为隔离的进程内 WPF 控件检查：测量各位数计数时的按钮坐标，验证圆环选中及取消、多选绑定、每个安装状态的文字和颜色绑定，以及原有搜索、编辑取消和自绘滚动条行为。状态预览由测试注入，不代表在本机再次安装业务软件。结果见 [公开验证摘要](../evidence/v0.9-ui/verification.json)。

五套安装引擎、京麦、缓存和自身更新回归共 252 项通过；进程内 WPF 控件检查 111 项通过，0 失败。当前 150% DPI 下，两种字体与三组字号的 36 个计数样本按钮位置均固定。真实用户配置及两个历史配置文件的 SHA-256 全部保持不变。
