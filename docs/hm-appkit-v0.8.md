# HM AppKit v0.8 界面调整

应用卡片保留三列，左侧 logo 右边依次为“应用名称 + 安装模式标签”和安装目录。模式标签使用绿色“静默”及灰色“常规”，跟随全局静默开关与应用支持情况更新；京麦使用常规安装及目录预填。

卡片右侧的铅笔编辑图标位于圆点选择控件左侧，垂直对齐，状态文本保留。圆点是独立多选开关，点击一个不会取消其他应用。安装根目录的编辑入口也改为相同图标。图标保留悬浮说明、可访问名称与键盘焦点。

岗位栏与操作栏分行排列；已选数量、全选、清空位于搜索框左边，搜索与添加位于右边。移除原“自动缓存 · 支持静默”卡片文字，将目标目录放到该位置。

应用列表与安装日志采用应用自己的细圆角滚动条，无系统箭头按钮。“跳过已安装”和“静默安装”采用 iOS 风格开关，新配置默认开启，旧配置中的用户选择继续读取。

底部细线是安装队列的总体进度，按终结状态的应用数量推进。生成安装计划时没有开始安装，因此进度为 0；它不是下载速度或单个厂商安装器的内部百分比。

主界面、窗口与执行文件图标采用本次提供的透明 PNG。PNG 保留原图内容，ICO 从同图转换为多种尺寸，用于不同 DPI 的 Windows 图标。

本次只调整展示和操作样式。固定 `Local Installer` 缓存、默认跳过已安装、静默参数、U 盘来源与内置磁盘目标策略，以及 HM AppKit 自身更新继续沿用 v0.7 行为。

验证结果：五套核心、缓存、京麦及自身更新回归共 252 项通过，隔离的 WPF 控件行为验证共 20 项通过。控件验证通过应用内的事件和命令检查多选、编辑取消、模式联动、拖动事件、翻页、搜索与日志滚动，没有向用户桌面注入鼠标或键盘输入，也没有安装业务软件。公共、全部岗位及日志展开状态均生成预览并检查，真实用户配置文件 SHA-256 保持不变。详见 [公开验证摘要](../evidence/v0.8-ui/verification.json)。
