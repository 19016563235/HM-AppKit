# 公开测试摘要

此目录保存实测的必要摘要，供源码和发布包中的验证记录引用，包括 v0.6 自身更新、v0.7 自动缓存与便携路径、v0.8 至 v0.12 界面行为验证与 v0.13 网络恢复验证。完整主机快照、安装包、用户设置和原始测试档案不公开。

公开副本将测试人员的工作目录及用户目录分别替换为 `%PROJECT_ROOT%`、`%USERPROFILE%`，将临时缓存、设置夹具和解包目录的随机标识替换为 `[cache-id]`、`[fixture-id]`、`[stage-id]`。这些占位符仅用于报告说明，不是程序实际路径。

测试结果、版本、厂商签名、安装包 SHA-256、安装目标和时间记录保持不变。本地 `artifacts/` 中的原始摘要未被修改；这些公开副本不能作为原始文件逐字节哈希验证的替代品。


v0.14 安装排序、位置异常、精简界面和更新重试验证见 v0.14-installation/verification.json。
