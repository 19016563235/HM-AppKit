# HM AppKit

Windows 装机助手：选择岗位、软件和安装位置，一键依次安装。默认从官方渠道获取当前版本，也可选择独立存放的本地安装包。第三方安装包不嵌入助手，不随发布压缩包分发。

v0.5 更名为 HM AppKit，新增默认开启的“保留安装包”和启动缓存更新检查。界面保留三列紧凑应用卡片、各应用真实品牌 logo 和 HM 主图标；安装路径、来源、状态和“修改”入口保留在卡片中。

## 使用

1. 打开 `HM AppKit.exe`。适用于 Windows 10/11 x64，发布包自带 .NET 运行时。内置应用使用官方直连；自定义 WinGet 应用需要微软应用安装程序（WinGet）。
2. 选择“在线最新版”或“本地安装包”。在线模式在安装时查询官方渠道；本地模式通过“选择安装包目录”读取安装包，默认参考目录为 `F:\客服软件`。
3. 点击“安装位置”中的目标盘，蓝色边框与底色表示当前选择。只显示可识别为内置固定磁盘的卷，排除 USB/UASP 外接硬盘、固态 U 盘、普通 U 盘等可移动设备。默认优先 D、E、F 等数据盘，最后选 C；点击“默认”可恢复自动选择，已选磁盘不可用时会阻止安装。
4. 默认安装到 `所选盘:\Software\应用目录名`。根目录需点击“修改”后确认，每款软件也可单独指定目录。
5. 按岗位勾选应用卡片，或输入名称搜索软件，点击“一键安装”。运营和客服共享的软件只安装一次，详细日志收在可展开区域。
6. “保留安装包”默认开启，可随时关闭，选择会随配置保存。保留的安装包位于 `HM AppKit.exe` 旁的 `Local Installer` 文件夹，与应用安装目录分开。

开启“保留安装包”时，启动只检查并更新已经缓存的在线安装包，不会批量下载尚未缓存的软件。仅启动助手或查看计划不会安装软件；点击安装会接受所选软件及适用的 WinGet 源协议，可能出现管理员权限确认。

在线模式查询官方当前版本，已有缓存可复用；未固定在上述本地版本。官网可能分批放量，取得的是该官方渠道当时提供的版本；WinGet 清单中的版本可能晚于官网更新。默认跳过已安装软件，不会自动升级或搬迁现有软件。

本地模式不修改原始安装包。七款平台软件记录了文件名、SHA-256、厂商签名和安装参数；文件缺失或校验不符时停止该项。外接盘可提供安装文件，但不能作为程序安装目标。公共软件和剪映没有本地配置，需切回在线模式。

2026-10-15 的 v0.4 本机实测中，六款平台软件完成在线下载、静默安装到 `E:\TempSoftware`，测试新增软件随后卸载；京麦两阶段安装需交互，当时严格静默模式跳过。飞书、微信、ToDesk、剪映因原已安装直接跳过。详见 [本机实测报告](docs/real-install-test-2026-10-15.md)、[来源记录](catalog/sources.md) 与 [本地安装包核验](catalog/local-installers.md)。

v0.5 对京麦使用“常规安装·预填目录”：向导将预填所选目标位置，请确认后继续安装；其他支持静默的软件仍优先静默执行。

本版的缓存复用、京麦实际安装及卸载清理结果见 [v0.5 验证记录](docs/hm-appkit-v0.5-test-2026-10-15.md)。公开的 [20 份测试摘要](evidence/README.md)保留版本、签名、哈希和核验结果，已脱敏测试人员的用户目录与随机临时目录；完整主机快照和厂商安装包不公开。

## 安装行为

- 默认优先静默安装；京麦等明确配置常规安装的应用会显示向导并预填目标目录。UAC、依赖安装、占用文件提示和厂商首次启动界面仍可能出现。
- 程序目录与聊天记录、素材、草稿、缓存目录不同，后者按应用自身设置管理。
- 修改目录不会搬迁已安装的软件，默认跳过现有软件。
- 官网直连仅接受配置中允许的 HTTPS 域名，下载后验证 Windows 数字签名与厂商名称；从 WinGet 清单解析的下载还核对清单中的校验值。
- 本地包先校验 SHA-256 和厂商签名，再用于安装；保留的包存放于程序旁 `Local Installer`，临时文件由助手管理和清理。
- 开启“保留安装包”时，启动更新检查只处理已缓存的在线安装包，并记录在日志中；不会自动安装或升级系统中的应用。
- 安装后核对目标位置，无法确认时显示“待核验”，不会仅凭退出码声称目录正确。
- 停止会等待当前安装结束再停止后续队列，不回滚已经完成的安装。

配置保存在 `%LocalAppData%\HM AppKit\settings.json`，日志位于同目录的 `Logs\`。升级依次检查 HM AppKit、HM-AutoSetup、FoxDeploy 的配置，保留自定义应用、各应用目录和安装选项，旧文件保留。更早版本的默认根目录 `CompanyApps` 会更新为 `Software`，用户自定义目录保持原值。

## 维护软件目录

默认目录嵌入 EXE，不含厂商安装程序。统一维护时，将源码 `catalog/catalog.json` 复制到 EXE 旁的 `Data/catalog.json`，该文件会覆盖内嵌目录。

`PackageId` 用于 WinGet；`OnlineInstaller` 配置官网动态地址、允许域名和签名发布者；`LocalInstaller` 配置外置文件名、SHA-256 与安装参数。`Roles` 可让同一软件属于多个岗位，应用 `Id` 保持唯一。替换本地版本前需重新核验，不能只改文件名或忽略哈希。

## 构建

安装 .NET 10 SDK，在包含 `FoxDeploy.sln` 的源码根目录执行：

```powershell
.\scripts\Build.ps1
```

v0.5 发布位置：`artifacts/HM-AppKit/v0.5/win-x64/HM AppKit.exe`，压缩包为 `artifacts/HM-AppKit/v0.5/HM-AppKit-win-x64.zip`。构建与自动化验证不会安装业务软件，也不会复制 `F:\客服软件` 或 `Local Installer` 中的安装包进入产物。

构建使用仓库中的 `evidence/` 公开摘要，不依赖本地测试产生的 `artifacts/`、已安装业务软件或历史主机快照。

京麦安装适配器使用 7-Zip 只读展开官方安装包。发布包保留 `licenses/7zip-license.txt` 和 `licenses/7zip-NOTICE.txt`，重新分发时应保留这些许可文件。
